ARCH 02

Standard linear chains fail because LLMs frequently mistake symptoms (e.g. checkout-service 504) for the actual root cause. TraceLog uses an 8-node cyclic Evaluator-Optimizer loop that autonomously pivots when hypotheses are contradicted.

ARCH 04

Hybrid GraphRAG & Topological Traversal

Vector embeddings alone fail in microservices because error logs across services share identical phrases. TraceLog multiplies semantic similarity by an exponential topological factor (1.5^depth), boosting true downstream root causes over upstream victim callers.
